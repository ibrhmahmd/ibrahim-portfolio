System Architecture

This project implements a genetic algorithm that progressively reproduces a target image through evolutionary operations. The algorithm uses selection, crossover, and mutation to evolve pixel configurations toward the target.

Population Init

Generate initial random population of image candidates (chromosomes).

Technical Deep-Dive

01. Genetic Operators

Implemented crossover and mutation operators that work on pixel-level chromosomes, combining parent traits and introducing random variations.

02. Fitness Function

Designed a MSE-based fitness function that quantifies similarity between candidate images and the target, driving selection pressure.

03. Selection Strategy

Used tournament selection to balance exploration and exploitation, choosing the fittest individuals for reproduction while maintaining diversity.

04. Hybrid Python/C

Optimized performance-critical operations in C while keeping the main algorithm in Python for rapid iteration and visualization.
