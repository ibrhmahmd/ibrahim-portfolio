YouTube Video Downloader

Streamlit Asynchronous Download Engine

GitHub
Streamlit Python Async yt-dlp Factory Pattern Strategy Pattern

System Architecture

This application implements a 3-tier architecture using Streamlit for the UI, a processing layer with Factory and Strategy patterns, and async download engines for high-throughput video processing.

User Input

User enters YouTube URL and selects download quality/format in Streamlit UI.

Technical Deep-Dive

01. Strategy Pattern

Implemented download strategies for different content types (video, audio, playlist) that encapsulate format-specific logic and quality selection.

02. Factory Pattern

Built a strategy factory that automatically selects the appropriate download strategy based on URL analysis and user preferences.

03. Async Processing

Used Python asyncio for non-blocking downloads with progress callbacks, allowing the Streamlit UI to remain responsive during long downloads.

04. Streamlit Integration

Created a responsive UI with Streamlit components for URL input, format selection, progress tracking, and download history.
