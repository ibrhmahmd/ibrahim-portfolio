WPF Tetris Game

C# Desktop Game with State Machine Architecture

GitHub
C# WPF XAML .NET State Machine Factory Method MVP Pattern

System Architecture

This Tetris implementation follows Model-View separation with a clean MVP architecture. The game logic runs in a state machine pattern, while block generation uses the Factory Method pattern for flexible piece creation.

Game Loop

State machine drives the main game loop with input processing and physics updates.

Technical Deep-Dive

01. State Machine Pattern

Implemented a finite state machine managing game states (Playing, Paused, Game Over) with clean transitions and state-specific behavior.

02. Factory Method

Used Factory Method pattern to generate random Tetris pieces, allowing easy extension for new piece types or custom generation rules.

03. MVP Architecture

Separated Model-View-Presenter concerns with clean interfaces, making the game logic testable independently of the WPF rendering layer.

04. XAML Data Binding

Leveraged WPF data binding and INotifyPropertyChanged to synchronize the game board matrix with the visual grid display.
