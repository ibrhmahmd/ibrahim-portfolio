System Architecture

A config-driven document generation pipeline with three independent entry points (Streamlit GUI, Python CLI, legacy PowerShell) converging on the same generator/ core. Reads JSON configs describing teams, students, skills, and phases — outputs polished HTML, PDF, and Markdown documents.

Entry Points

Three independent entry points: Streamlit GUI for interactive data entry, Python CLI for batch processing, and legacy PowerShell script. All converge on the same generator core.

Technical Deep Dive

01. Config-Driven Pipeline

JSON config files describe teams, students, skills, phases, and achievements. config.py handles legacy format normalization, default injection (colors, banners, labels), and validation. 11 team configs across 4 categories (Software, Healthcare, Game, Marketing).

02. Bilingual EN/AR Support

Full English + Arabic bilingual support throughout. RTL Arabic text at every level — student names, course names, objectives, deliverables, descriptions, achievements. Streamlit UI has a language toggle with complete translation dictionaries. Generated documents render both languages.

03. Skill Categorization Engine

skills.py automatically classifies any named skill into 6 categories (Computational Thinking, Iterative Logic, Collaboration, Creative Problem-Solving, Academic Cross-Transfer, Competition Readiness) using regex pattern matching. Generates hexagonal SVG radar charts for each student profile.

04. Three Entry Points

Streamlit GUI — interactive web app with live preview, CRUD for configs/students, session state management. Python CLI — batch processing with flags for team/student selection. PowerShell — legacy Edge headless PDF, superseded by CLI. All converge on the same generator/ core.

05. PDF Rendering via Playwright

A4 print-ready PDFs rendered via Playwright headless Chromium. Asset inlining converts CSS links and logo images to inline styles and base64 data URIs for self-contained output. Dual mode: local Chromium or cloud Chromium via Steel API.

06. Two Document Types

Team Timeline — full project overview with zigzag phase layout, skills matrix, stats, instructor notes, Arabic overlay. Student Profile — individual milestone profile with overview bar, skills radar chart, achievements, prep plan, and phase breakdown. Both output HTML, PDF, and Markdown.
