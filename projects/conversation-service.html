System Architecture

ConversationService acts as the system coordinator for processing chat histories, RAG inputs, and prompt pipelines. It uses **Semantic Kernel** to model LLM connections, stores structured messages via **Entity Framework Core**, buffers context records over **Redis**, and generates vectors dynamically to match contextual documents on a **Pinecone database**.

Technical Deep-Dive

01. Semantic Kernel Orchestration

Integrated Microsoft’s **Semantic Kernel** to construct AI pipelines. This aggregates systemic prompts, handles chat agent memories, and communicates directly with downstream Ollama nodes using custom type-safe configurations.

02. Vector RAG Pipeline

Built a custom Retrieval-Augmented Generation (RAG) connector utilizing **Pinecone**. User text uploads are parsed into embeddings and queried against a Pinecone vector schema to supply context boundaries back to models.

03. Strategic History Caching

By leveraging Redis cache policies, user history items and prompt templates are fetched in sub-100ms timescales. Handled cache expirations to secure chat mutations without overloading the SQL instances.

04. Streaming with Server-Sent Events (SSE)

Instead of bulky polling, ConversationService utilizes .NET 9 asynchronous iterators to stream model outputs dynamically back to clients using HTTP Server-Sent Events (SSE) for raw low-latency updates.
