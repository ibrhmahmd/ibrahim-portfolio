Ollama HTTP Factory

High-Resilience C# HttpClient Library

GitHub
C# .NET HttpClient Connection Pooling Resilience Patterns Factory Pattern

System Architecture

This library implements a factory pattern for creating resilient HTTP clients with built-in connection pooling, retry policies, and circuit breaker patterns. Designed for distributed LLM deployments where network reliability is critical.

Client Request

Application requests an HttpClient instance from the factory.

Technical Deep-Dive

01. Factory Pattern Implementation

Built a typed factory that creates pre-configured HttpClient instances with appropriate timeout, header, and policy settings for different LLM endpoints.

02. Connection Pooling

Implemented connection pooling to reuse HttpClient instances across requests, reducing socket exhaustion and improving throughput in high-concurrency scenarios.

03. Polly Resilience Policies

Integrated Polly policies including retry with exponential backoff, circuit breaker for fault isolation, and timeout policies for graceful degradation.

04. Health Monitoring

Added health check endpoints that monitor connection pool status, track request metrics, and provide observability into client performance.
