Ibn Battuta Game

Historical Exploration Game · Python

GitHub
Python Pygame Zero Pygame State Machine Screen Management 2D Game Dev

Game Architecture

A screen-state game built with Pygame Zero. The main loop delegates to per-screen modules — each level, the world map, and the start screen handle their own draw(), update(), and input events. A global current_screen variable drives navigation.

Main Loop

pgzrun.go() drives the game loop. draw() and update() dispatch to the current screen module.

Technical Deep Dive

01. Screen-State Architecture

A single current_screen string drives all navigation. The main loop's draw(), update(), and input handlers dispatch to the active screen module via if/elif chains. Each screen is a standalone Python module with its own state — no shared mutable globals between levels.

02. Five Historical Levels

Each city (Tangier, Fez, Cairo, Damascus, Timbuktu) is a self-contained level module with unique sprite assets, game mechanics, and mission objectives. Players explore historical locations tied to Ibn Battuta's 14th-century travels across North Africa and the Middle East.

03. World Map Navigation

A clickable world map screen lets players select which city to visit. The map uses positioned hitboxes for each region, transitioning to the selected level module on click. Provides a non-linear exploration experience.

04. Mission Overlay System

mission_overlay.py renders contextual briefings and historical information on top of active levels. Provides game objectives, historical context about each city, and progression cues without interrupting gameplay.

05. Audio & Mute Toggle

Background music plays across screens via pgzero.builtins.music. A persistent mute toggle button (Actor-based UI) sits at the top-right corner across all screens, with music.play() / music.stop() toggling.

06. Pygame Zero Integration

Built on Pygame Zero — no explicit Pygame boilerplate. The framework handles the game loop, rendering, input events, and asset loading. pgzrun.go() starts the loop; Actor objects handle sprites and collision detection.
