NeoStreamJS

Zero-Build Reactive Web Framework

GitHub
Node.js Express WebSockets JavaScript Reactive Architecture Real-time Sync

System Architecture

NeoStreamJS implements a bidirectional reactive state synchronization pattern between client and server. The framework eliminates build steps by leveraging native ES modules and WebSocket connections to propagate state changes in real-time across connected clients.

Client Connection

Browser connects via WebSocket and establishes initial state subscription.

Technical Deep-Dive

01. Bidirectional State Sync

Implemented a custom reactive state management layer that synchronizes client and server state via WebSocket messages. Uses a diff-based approach to minimize payload size during updates.

02. Zero-Build Architecture

Eliminated build tooling by leveraging native ES modules and dynamic imports. The framework runs directly in modern browsers without transpilation or bundling steps.

03. Express.js Integration

Built as an Express middleware that automatically handles WebSocket upgrade requests and manages connection lifecycle, including reconnection and heartbeat monitoring.

04. Subscription Management

Implemented a pub/sub pattern where clients subscribe to specific state channels. The server maintains a subscription registry and broadcasts only relevant updates to each client.
