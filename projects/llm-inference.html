LLM Inference

Distributed Local LLM Deployment & Public Exposer

System Architecture

LLM Inference provides a pipeline to expose local computing power to public applications. A local instance runs **Ollama** models inside a python/notebook process. An **ngrok tunnel** dynamically exposes the REST endpoint while a **RabbitMQ discovery agent** publishes the tunnel URL and health status to a centralized queue for client consumption.

Technical Deep-Dive

01. Secure Tunnel Exposer

By leveraging **ngrok API libraries**, the pipeline creates a secure public TCP/HTTP endpoint pointing directly to the local Uvicorn/FastAPI daemon, bypassing firewalls and routers dynamically.

02. RabbitMQ Registry Exchange

When a local model instance initializes, it publishes its unique ngrok public URL and supported model types to a shared **RabbitMQ discovery topic**. Client applications query this registry to locate live nodes.

03. Uvicorn/FastAPI Gateway

An async FastAPI server running on Uvicorn maps standard REST endpoints onto the local Ollama REST backend, performing parameters checks and handling concurrent stream formatting automatically.

04. Python-First Orchestration

Constructed within a **Jupyter Notebook-friendly** architecture, developers can spin up, configure model types (e.g. Llama 3, Phi 3), authenticate tunnels, and connect registers in single execution steps.
