TensorFlow Flower Classifier

Computer Vision CNN for Image Classification

GitHub
TensorFlow Python CNN Keras Deep Learning Data Augmentation

System Architecture

This project implements a Convolutional Neural Network using TensorFlow/Keras for classifying flower species. The model uses data augmentation and dropout layers to achieve >90% validation accuracy.

Data Pipeline

Load flower images, apply augmentation, and prepare batches for training.

Technical Deep-Dive

01. CNN Architecture

Designed a sequential CNN with alternating convolutional and pooling layers, followed by dense layers for classification.

02. Data Augmentation

Applied real-time augmentation (rotation, flip, zoom, brightness) to increase training data diversity and prevent overfitting.

03. Regularization

Used dropout layers (0.5 rate) and early stopping to reduce overfitting and improve generalization to unseen images.

04. Training Pipeline

Built an efficient training pipeline with batch processing, learning rate scheduling, and model checkpointing for optimal results.
