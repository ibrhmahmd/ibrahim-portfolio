System Architecture

A Vertical Slice Architecture FastAPI application with Unit of Work + Repository pattern. The system generates print-ready A4 certificates via headless Chromium, embeds QR codes for public verification, and provides a full management UI with HTMX-powered partial updates.

Web UI Layer

Jinja2-rendered pages with HTMX 2.0 for dynamic partial updates. Dashboard, Generate form, Registry, and Verify pages.

Technical Deep Dive

01. Vertical Slice Architecture

Each domain feature is a self-contained slice: modules/certificates/ contains models, schemas, validators, repositories, services, and assets. Clean separation between Business Logic (CertificateCrudService) and Rendering (CertificateRenderService). Protocol-based interfaces enable dependency inversion.

02. Certificate Rendering Pipeline

HTML certificates rendered via Jinja2 templates with per-track accent colors (14 tracks). PDF output uses Playwright headless Chromium for pixel-perfect A4 landscape rendering. Self-contained HTML output embeds base64 logos and fonts. QR codes generated per certificate linking to public verification endpoints.

03. Unit of Work + Repository Pattern

CertificatesUnitOfWork wraps the DB session and coordinates two repositories (certificates + audit log) with shared commit/rollback. Protocol-based interfaces (CertificateRepositoryInterface, CertificateServiceInterface) are @runtime_checkable for substitutable implementations.

04. HTMX-Powered Web UI

Full management dashboard with HTMX 2.0 partial updates — no full page reloads. Dashboard with stats, certificate generation form, searchable/filterable registry with pagination, and public verification page. Tailwind CSS for styling, Google Fonts for typography.

05. Audit Trail & Revocation

Every generate and revoke action is logged to certificate_audit_log with actor info and metadata. Revocations include timestamped reasons. Soft-delete pattern preserves certificate history while removing from active registry.

06. 14 Track-Specific Themes

Each course track (HTML, CSS, JavaScript, Python, Advanced, Problem Solving, 5 Robotics variants, Scratch, Scratch Jr, LEGO STEAM PARK) has its own accent color and logo. Track-specific branding applied to certificate design, QR code generation, and web UI.
